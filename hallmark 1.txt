## Objective
Establish a reusable Hallmark Coral design system for my existing Next.js web and Flutter mobile applications.

**This task is ONLY for establishing shared design tokens and theme foundations. DO NOT redesign any pages or screens yet.**

## Phase 1 — Inspect and extract

1. Read the Hallmark Coral theme documentation and relevant design rules.
2. Inspect only the existing shared theme, style and UI configuration files in the Next.js project.
3. Extract the Coral design values and principles, including:
   - Primary, secondary, background and surface colors
   - Text, muted text and border colors
   - Success, warning, error and disabled states
   - Typography, font sizes and weights
   - Spacing scale
   - Border radii
   - Shadows and elevation
   - Button, input, card and form styling
   - Hover, focus and interaction states
4. Use official Hallmark values wherever provided. If a value is unspecified, choose a compatible value and clearly identify it as an implementation decision.

`design-tokens/coral.tokens.json`

This should become the canonical source of truth for both web and mobile.

Use semantic token names rather than page-specific colors or arbitrary values.

Create concise documentation:

`design-tokens/README.md`

Explain how the tokens map to Next.js and Flutter.
